# React Blogs App

## Description

This is a React-based frontend application for a blogging platform. It allows users to register, log in, view blogs, read detailed blog posts, and create or edit their own blogs. The app is built with modern React practices, using Vite for fast development and deployment. It integrates with a backend API for data management and user authentication.

## Deployment

The application is deployed on Netlify. You can access the live version here: [https://very-cool-react-blogs-app.netlify.app/](https://very-cool-react-blogs-app.netlify.app/)

## Backend

The backend for this application is available on GitHub: [https://github.com/RoaaFouda/blogs-app-backend](https://github.com/RoaaFouda/blogs-app-backend)

## Features

- **User Authentication**: Secure login and registration system to manage user accounts.
- **Blog Listing**: Display a list of all available blogs on the main page.
- **Blog Details**: View detailed content of individual blog posts.
- **Blog Creation and Editing**: Users can create new blogs or edit existing ones through a dedicated form.
- **Responsive Navigation**: A navbar component for easy navigation across the app.
- **State Management**: Uses React Context (UserProvider) to manage user state across the application.
- **API Integration**: Axios is used for making HTTP requests to the backend API.
- **Modern UI**: Styled with CSS for a clean and responsive user interface.

## Tech Stack

- **Frontend**: React, Vite
- **Styling**: CSS
- **HTTP Client**: Axios
- **State Management**: React Context API
- **Build Tool**: Vite

## Installation and Setup

1. Clone the repository:
   ```
   git clone <your-frontend-repo-url>
   cd frontend
   ```

2. Install dependencies:
   ```
   npm install
   ```

3. Start the development server:
   ```
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173` (or the port specified by Vite).

## Usage

- Register a new account or log in with existing credentials.
- Browse the list of blogs on the home page.
- Click on a blog to view its details.
- Use the blog form to create or edit blogs.
- Navigate using the navbar for different sections.
